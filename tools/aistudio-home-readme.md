# Maryam Jaberi — home page and CV (AI Studio copy)

This repo holds only part of the site: the English home page (`index.html`), the Persian home page (`fa/`), case studies (`case/`), the CV (`cv.html`, `cv.pdf`) and `assets/`.
The main repo is `MaryamJaberi/MaryamJaberi.github.io`. Every change here goes there automatically as a Pull Request and is published after Maryam approves it. Do not push to this repo directly.

## Important when editing

- `index.html`, `fa/index.html`, `case/*.html` and `404.html` are generated by `tools/build.py`. **Change the copy in its `EN` and `FA` dictionaries**, not only in the HTML; otherwise the next build overwrites it.
- Styling lives in `assets/site.css`; design rules in `tools/DESIGN.md`.
- Screenshots per language live in `assets/img/en` and `assets/img/fa`.
- Links such as `daneshsara/`, `mafia/` and `wellbeing-check/` point to other parts of the site that are not in this repo; they don't work in the AI Studio preview, which is expected.
- Never put keys or passwords in the repo.
