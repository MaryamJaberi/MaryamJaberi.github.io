# نمونهٔ اولیهٔ React (مرجع طراحی — منتشر نمی‌شود)

این پوشه کد مخزن قدیمی `chrono-atlas` است: یک اپ React + Vite + TypeScript که
هیچ‌وقت ساخته و منتشر نشد (نشانی `maryamjaberi.github.io/chrono-atlas` همیشه ۴۰۴ می‌داد).

**سایت زنده این پوشه نیست.** سایت همان صفحه‌های ریشهٔ مخزن است (`index.html` و فایل‌های
جاوااسکریپت کنارش). این پوشه فقط برای نگه‌داشتن طراحی و داده‌های آن نمونه است.

## چه چیزی از این نمونه به کار آمد

داده‌هایش به JSON تبدیل و در `data/atlas/` گذاشته شدند، تا سایت اصلی بتواند از آن‌ها
استفاده کند بدون اینکه به React و مرحلهٔ ساخت نیاز داشته باشد:

- `atlasData.json` — دوران‌های دیرینه‌جغرافیا، شاخه‌های حیات، انقراض‌های بزرگ،
  کاتالوگ تمدن‌ها، سلسله‌های فلات ایران، پنل‌های موضوعی ایران، و فهرست منابع علمی
- `thematicMapData.json` — مرزهای تاریخی، موجودیت‌های موضوعی و پیکربندی لایه‌ها

## ایده‌های طراحی که ارزش برداشتن دارند

- **لنزها** به‌جای لایه‌ها: زمین، حیات، تمدن‌ها، ایران، منابع — هرکدام یک نما روی همان زمان
- **نوار زمان اصلی** به‌عنوان کنترل مشترک همهٔ لنزها (`MasterTimelineController`)
- **پنل زمینه‌ای** که با حرکت زمان محتوایش عوض می‌شود (`ContextualPanel`)
- **لنز منابع** که منبع هر داده را کنار خودش نشان می‌دهد (`LensSources`)

## دو هشدار

1. رابط این نمونه می‌گوید «۲۸ دوره و ۹۸ رویداد مستند»، ولی `IRAN_DYNASTIES_DATA`
   در عمل ۹ سلسله دارد. این عدد در رابط، پشتوانهٔ داده‌ای ندارد و اگر چیزی از این
   نمونه برداشته شد، نباید با خودش برود.
2. `package.json` به `@google/genai` وابسته است. هیچ کلیدی در مخزن نیست و نباید
   باشد؛ اگر روزی این نمونه ساخته شود، کلید باید از متغیر محیطی بیاید.

## اگر روزی خواستی اجرایش کنی

```bash
cd prototype
npm install
npm run dev
```
